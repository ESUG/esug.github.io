Slides of ESUG2026

-> Every day has a subfolder
-> talks are are numbered in order they were given:
	- first digit represents the day
	- next 2 digits represent the number of presentation that day
	- then a dash and 4 letters of the last name of the speaker 
	- then a dash and presentation title
-> IWST talks follow the same pattern but start with "iwst"

e.g.:

- 401-duca-what-devs-are-doing-with-pharo.pdf (Day 4, presentation 01, speaker Stéphane DUCAsse)
- iwst-205-cipr-coypu.pdf (Day 2 of IWST, presentation 05, speaker Domenico CIPRiani)

This way, slides remain ordered even when dumped into a single folder and you can easily find a file if you remember the speaker.

All slides are in PDF.
Pablo's slides from Day 1 also have a folder with HTML and assets because he has many videos a stale PDF would make his presentation less meaningful

Slides are on SlideShare: https://www.slideshare.net/esug/presentations
